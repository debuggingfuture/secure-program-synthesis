# ADR-001 — Project name

**Status:** proposed. Not blocking; rename is `git mv` + a few find/replace.

## Working name: VAPOR

*Verified Access Policy Over Retrieval.* Evokes "context = vapor in the
air" and rhymes with the agent-memory framing.

## Alternatives considered

- **LAMINA** — Lean-verified Access Mediator for Iterative aNalytic
  Agents. Long.
- **CIRRUS** — Capability-IR for Retrieval, Rewrite, and Underlying
  Sources. Cute, conflicts with existing Cisco/AWS products.
- **AGORA** — Agentic Governance Over Retrieval Algebra. Conflicts with
  too many things.
- **COVENANT** — emphasizes "decoupled policy as contract." Heavy.

## Decision

Use VAPOR in paper drafts and code. Final name decided before
submission; user to confirm.
